# 🐍 Fundamentos de Programación - Fase 04

Este repositorio contiene la solución de los **Problemas 01** al **Problema 05** del curso. 

## 📖 Acerca de esta Fase

El objetivo principal de esta etapa es afianzar las buenas prácticas de programación y el aseguramiento de la calidad del software.

*   **Depuración asistida por IA:** Identificación y corrección estructurada de errores generados conscientemente en el código.
*   **Código limpio (*Clean Code*):** Optimización de la lógica implementanda para mejorar su legibilidad y aplicación de estándares en el nombramiento de variables y constantes.
*   **Manejo de excepciones:** Control de errores para evitar interrupciones inesperadas y garantizar la estabilidad de los programas.
*   **Documentación de código:** Implementación de comentarios claros y descriptivos en la definición de las funciones.

## 📂 Contenido del Proyecto

*   `2203_Fase4_ZamirDiaz_Problema01.py`: Sistematización de la venta de entradas y la gestión de asientos para una única sala del cinema "Cine Full".
*   `2203_Fase4_ZamirDiaz_Problema02.py`: Automatización del registro mensual de ventas de una empresa. El sistema evalúa el desempeño del equipo y determina si los vendedores califican para un bono, basándose en un límite predefinido, eliminando la gestión manual.
*   `2203_Fase4_ZamirDiaz_Problema03.py`: Sistema para Recursos Humanos que automatiza el cálculo de salarios brutos y netos. Procesa una lista de empleados (horas trabajadas y tarifa), aplica un descuento fijo del 15% y genera un informe final libre de errores manuales.
*   `2203_Fase4_ZamirDiaz_Problema04.py`: Optimización de inventario para una tienda minorista. El algoritmo procesa los datos de los productos, los compara con un umbral de seguridad, recomienda la cantidad a pedir y clasifica la prioridad de reposición.
*   `2203_Fase4_ZamirDiaz_Problema05.py`: Herramienta de gestión de proyectos que utiliza una estructura de matriz para representar y visualizar la asignación de recursos. Permite manipular y analizar el estado de las diferentes tareas del equipo.
