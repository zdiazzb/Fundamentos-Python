# 🐍 Fundamentos de Programación - Fase 03

Este repositorio contiene la solución a los **Problemas 05 y 08** de la asignatura.

## 📖 Acerca de esta Fase

El objetivo principal de esta etapa es dominar el uso de arreglos (*arrays*) y estructuras repetitivas. La combinación de ambos conceptos permite gestionar grandes volúmenes de información y automatizar procesos con eficiencia. Para ello, las soluciones desarrolladas integran:

*   **Manejo de Arreglos:** Almacenamiento, recorrido y manipulación de conjuntos de datos dentro de una misma estructura.
*   **Estructuras repetitivas:** Uso de bucles `while`/`for` para ejecutar tareas iterativas de forma controlada mientras una condición sea verdadera.

## 📂 Contenido del Proyecto

*   `2203_Fase3_ZamirDiaz_Problema05.py`: Archivo principal que implementa la solución al problema enfocado en el uso de **estructuras repetitivas**.
*   `2203_Fase3_ZamirDiaz_Problema08.py`: Archivo principal que contiene la lógica de la solución al problema centrado en la manipulación de **arreglos**.
